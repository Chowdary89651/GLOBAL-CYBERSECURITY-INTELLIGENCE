# Global Cybersecurity Intelligence Dashboard

## Project Overview
This project analyzes global cybersecurity incidents using Power BI. It provides insights into cyber attack trends, affected countries, industries, attack types, and financial impact.

## Tools Used
- Power BI
- Microsoft Excel
- Power Query
- DAX

## Dashboard Features
- Total Cyber Attacks
- Top Affected Countries
- Attack Type Analysis
- Industry-wise Impact
- Financial Loss Analysis
- Year-wise Cyber Attack Trends
- Interactive Slicers and Filters
